# pokerhands_mlp
O dataset escolhido consiste em registros de mãos de pôquer, cada uma composta por cinco cartas extraídas de um baralho padrão de 52 cartas. Cada carta é descrita por dois atributos: naipes (suit) e valores (rank). O objetivo deste estudo é prever a classificação das mãos de pôquer com base nas cartas apresentadas.
